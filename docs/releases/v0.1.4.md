# Eveys GIB ESU Reporter 0.1.4

## Duzeltmeler

- Windows/macOS/Linux paketlerinde `javax/xml/crypto/dsig/XMLSignContext` hatasina neden olan eksik Java modulleri eklendi. XML imzalama, HTTP istemcisi ve PKCS#11 destegi uygulamanin kendi Java'sinda bulunur.
- Masaustu ciktilari varsayilan olarak kullanici klasorundeki `EveysGibEsuReporter/out-desktop` altina yazilir. macOS Finder'dan acilista `/out-desktop: Read-only file system` hatasi duzeltildi.
- Hatali veya kilitli PIN durumlari acikca belirtilir. PIN hatalarinda otomatik olarak baska slotlarda giris denenmez.
- Basarisiz islemden sonra durum alani artik "Test devam ediyor" olarak kalmaz.

## Guncelleme

- **Windows:** `EveysGibEsuReporter-0.1.4-windows.zip` dosyasinin tamamini yeni bir klasore cikarin. O klasordeki `EveysGibEsuReporter.exe` dosyasini acin. Yalnizca EXE'yi eski klasore kopyalamayin; `app` ve `runtime` klasorleri de yenilenmelidir.
- **macOS:** DMG icindeki uygulamayla Applications'taki eski uygulamayi degistirin.
- **Linux:** Yeni tar.gz paketini ayri bir klasore cikarin ve icindeki launcher'i kullanin.
- Mevcut sirket ayarlari kullanici klasorundeki `.eveys-gib-esu/application.yml` dosyasinda kalir. Eski raporlar tasinmaz veya silinmez; gerektiginde Cikti Klasoru alanindan eski konumu secebilirsiniz.
- Masaustu paketleri Java'yi icerir. Mali muhur icin isletim sistemine uygun AKIS/kart okuyucu surucusu yine gereklidir.

## Paket Kontrolleri

Her isletim sisteminin paketi, kendi Java'siyla ornek Excel okuma, XML uretimi, ECDSA imzalama/dogrulama, gomulu XSD dogrulamasi, ZIP olusturma ve gerekli Java bilesenlerini kontrol eder. Bu kontrol basarisizsa release yayimlanmaz.

Otomatik kontroller ornek veri ve gecici yazilim anahtari kullanir; fiziksel mali muhur veya GIB sunucusuna gonderim icermez. AKIS surucusu ve fiziksel kartin Windows'ta dogrulanmasi kullanici bilgisayarinda yapilmalidir.
